# ScVEMO File outline

## 10XMouse_preprocessing.R

R file containing preprocessing Seurat and Signac for sccRNA, scATAC, multiomics and Multivelo based models. 

## Simulations

Files containing models simulations are respectively named as *_run.py*

## Model and Transition Matrix

Transition matrix computations and deterministic models can be found in *transitionMatrix.py* and *model.py*. Transition matrix analysis can be found in *matrix_analysis.py*

## Utility functions

utility and multiple purpose functions can be found in *utils.py*.
